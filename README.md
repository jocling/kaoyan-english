# 英语工作台（考研英语二）

真题阅读训练页面，单文件、不依赖任何 AI 登录。

- 页面：`index.html`（GitHub Pages 发布）
- 每篇两种模式：
  - **答题模式**：限时 18 分钟、点词标"不认识"、点句首圆点标"没读懂"、提交出答题卡（每题正确答案，红绿标对错）
  - **精读模式**：句子编号、P 段标、重难点词蓝色高亮；点任何词弹出释义（本文语境释义＋词典释义，词典来自开源 ECDICT）；每段下方逐句译文；每题带解析
- 右上角【保存】：答题提交后保存本次作答；精读模式保存补标的词句。设置了令牌就直接写进本仓库
- 「答题卡」页：16 篇总览，按每篇最近一次作答计分
- 做题记录：`records/attempts.json`（页面自动写入；`attempts` 为每次作答，`notes` 为精读时补标的词句）
- 每周复盘/巩固内容：`coach/`（AI 按周更新）

译文、重难点词、解析都预存在 `index.html` 里（加新真题时一并生成），不接在线模型。数据仅为个人备考记录。
